# pgdumpx 0.2.0

`pgdumpx 0.2.0` is the first public release of the read-only Rust library and CLI for bounded inspection, extraction, and row scanning of PostgreSQL custom-format dumps.

## Highlights

- Inspect archive metadata and table entries without restoring into a PostgreSQL server.
- Stream selected raw entry bodies with explicit decompressed-byte limits and typed partial-output failures.
- Parse PostgreSQL COPY text rows as bytes, distinguish NULL from non-NULL values, and scan exact named-column matches with finite default budgets.
- Reuse owned selectors, metadata filters, extraction plans, and sequential multi-table extraction from library code.
- Use `inspect`, `list`, `extract`, and `find` from the `pgdumpx` CLI.

## Supported boundaries

- Archive versions 1.14 through 1.16 are fixture- and differential-verified.
- none, gzip, LZ4, and Zstandard selected-entry decompression is supported.
- COPY text row access is supported. Binary COPY and INSERT-based row decoding are not supported; readable INSERT entries can still be extracted as raw bytes.
- Rust 1.85.0 is the MSRV.
- Linux, macOS, and Windows are exercised by CI.

## Reliability and maintenance

The release includes separate structural, raw-output, row, and decompressed-byte limits; warning-denying tests and documentation; official fixture provenance; compatibility differential checks; fuzz smoke and scheduled coverage-guided campaigns; dependency advisory checks; package-content audits; and immutable, least-privilege workflow dependencies.

## Installation

After both crates.io packages are published:

```bash
cargo install pgdumpx-cli --version 0.2.0 --locked
pgdumpx --help
```

Library consumers can add:

```toml
[dependencies]
pgdumpx = "0.2.0"
```

See `README.md`, `docs/COMPATIBILITY.md`, `docs/PACKAGING.md`, and `SECURITY.md` for complete support and safety boundaries.
